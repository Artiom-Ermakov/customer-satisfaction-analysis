# customer-satisfaction-analysis

Провёл анализ условий работы климатического оборудования в офисах разных
стран для выявления факторов, влияющих на комфорт сотрудников: выполнил
предобработку и исследовательский анализ данных, сегментацию, проверку
статистических гипотез и сравнение моделей прогнозирования температуры.
Выявил обратную взаимосвязь между количеством рекламаций и оценкой
комфорта, а также статистически значимые различия по странам, климату и полу.
Результаты представил в дашборде и сформулировал рекомендации по настройке
оборудования, сервисному обслуживанию и региональной стратегии инвестиций.

*Стек технологий:* Python (Pandas, NumPy, Matplotlib, Seaborn, sklearn, SciPy),
Jupyter Notebook, Yandex DataLens, Figma.
